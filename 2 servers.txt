FILE-BASED CSE / nonCSE APP CONSOLIDATION

# Drive layout under APP SYSTEM FILES
#   (folder id 1WwsC0Le5uo71jSzZlYsEnQT5MGWTnjq6 — rclone remote "gdrive"):
#
# Office folder name = short code from Office.code (strip leading O- / O_):
#   O-BAC → BAC, O-CHO → CHO, IT → IT
#
# Sources (office PPMPs):
#   Drive CSE-PPMP/{short}    ↔  C:\xampp\htdocs\appbac\IT_ppmps\CSE\{short}
#   Drive nonCSE-PPMP/{short} ↔  C:\xampp\htdocs\appbac\IT_ppmps\nonCSE\{short}
#   (office folders e.g. BAC, ADMIN, IT — Excel files listed recursively)
#
# End-user PPMP upload (POST /api/offices/ppmps/upload):
#   saves under local IT_ppmps/{CSE|nonCSE}/{short}/ AND rclone-copies to the
#   matching Drive CSE-PPMP|nonCSE-PPMP/{short}/ folder (local+DB succeed even
#   if Drive push fails; response includes drive_sync).
#
# bacadmin create/reactivate office (POST /api/bac/offices):
#   ensures CSE-PPMP/{short} and nonCSE-PPMP/{short} exist (creates or reconnects
#   to an existing case-insensitive match). Soft-delete never removes Drive folders.
#
# Outputs (consolidated APP uploaded after Run Consolidation):
#   local export → Drive CSE-APP / nonCSE-APP
#
# CSE-APP tab lists CSE folder; nonCSE-APP tab lists nonCSE folder.
# Opening either tab (or clicking Sync from Drive) runs:
#   POST /api/bac/ppmps/sync-from-drive?kind=cse|noncse
# which rclone-syncs the matching Drive PPMP folder into IT_ppmps.
